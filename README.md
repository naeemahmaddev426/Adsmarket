# AdsMarket

AdsMarket is a classified ads platform built with Laravel, PHP and MySQL.

## Features

- User Authentication
- Ad Posting System
- Categories & Subcategories
- Search & Filtering
- Admin Dashboard
- Image Uploads

## Tech Stack

- Laravel
- PHP
- MySQL
- JavaScript
- Bootstrap

## Installation

```bash
composer install
cp .env.example .env
php artisan key:generate
php artisan migrate
php artisan serve
```
